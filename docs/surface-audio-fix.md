# 点词完整读音修复 · 2026-09-21

原点词按钮主要播放词典原形。例如「주차했어요?」只提供「주차하다」，「약을」只提供「약」，「먹으니」只提供「먹다」，遗漏句子中出现的助词或词尾。

现在所有 44,985 个可点击词块都提供「听句中词形」，覆盖 16,374 个不同完整词形；新增 13,660 段音频，复用 2,714 段已有音频，缺失 0。原形另设「听原形」，相同音频不重复显示；「听整句」继续保留。点击词块仍先打开注释，再按对应按钮播放。

词形保留全部音节、助词和词尾，仅去掉两端标点。大部分按完整书写形式单独合成，并非从句子逐词切割；跨词连读与整句语调应通过整句播放学习。「놨거든」采用原句的已记录区间，保留源文件哈希与截取范围。原有 15,117 段音频的 URL 和字节全部保持不变。
