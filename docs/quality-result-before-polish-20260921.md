## 内容修正与实际覆盖

本轮完整阅读了语义扫描中剩余待处理的 216 个关卡的两段韩中对话、当前词义及解释，并记录采纳或拒绝建议的理由。累计定向复核账本覆盖 280 个不同关卡；模型报告的疑点不等于确认错误，拒绝错误建议也不计作修正。此前另有完整句子的 AI 编辑审校记录，本次没有把 216 关定向工作描述成重新独立翻译了整个词典。

显式编辑账本记录 **101 个位置：90 处词块注释、11 处整句中文**。来源选择和通用规则重新生成后，相比上一轮共有 **563 关中的 635 个词块**发生变化，其中 63 处词源选择发生变化；这是生成差异统计，不能与 101 个显式位置相加称为错误总量。

- 区分 `네` 的“四、你的、是的”、`사내` 的“男子/男孩”与“公司内部”，修正 `옴` 的“疥疮”、`올` 的“线股”、`장` 的“买菜/市场”等语境。
- 校正动作完成的 `-아/어 버리다`、尊敬持续状态的 `-고 계시다`，将句末疑问与表示原因或连接的同形语尾分开；183 处疑问语尾说明得到修正。
- 解释 `언니/누나/형/오빠` 与说话人性别的关系，补足 `조카` 包含侄辈与甥辈的范围；亲属关系不能从上下文唯一确定时保留限定说明。
- 组合真正的复合数词，保留“工作、公司、你的”等同音词义；`삼사 도` 表示“三四度”，不误合成“34 度”。
- 调整时态、程度、数量、对象与语境不一致的整句中文。韩文原句、发言顺序、说话人、关卡身份与答案位置均保持兼容。

选择依据包括来源词典的词条及义项、完整对话语境，以及国语院对[尊敬助动词 계시다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=61346&nation=eng)等用法的说明。每项编辑保留理由，已确认问题加入内容回归检查；`밝다` 与 `받다`、近似数量与十进制数字等相邻风险也有反向检查。

证据：[显式修正账本](editorial-corrections-extreme-20260921.json)、[范围汇总](extreme-review-summary.json)、[逐关复核决定](whole-course-semantic-triage.jsonl)、[课程身份兼容](course-compatibility.json)。

## 新编听力对比题

新增 128 道题逐句编写同场景干扰项，比较时间、人物、数量、否定与具体动作。例如房租对话区分“什么时候交”“交给谁”“多少钱”，日期区分“每月四号”“每月三号”“每周四”。所有正确答案与当前整句中文一致，每题有三个不同选项。

当前共 **102 关、204 道编辑对比题**；其余 3,904 关继续使用先听、主动回忆、展开核对及自评的流程。回忆自评明确标注，不冒充客观听力成绩。使用提示、第一次答错或未完整听完都会影响复习安排。新题保持旧答案位置，兼容已经打开的旧客户端。

本地浏览器实际走通新题的完整听音、选项解锁、首次答错、改正及提示辅助流程。详见[新题逐项记录](listening-contrasts-extreme-20260921.json)。这项改进增加了题目质量与覆盖，但没有补齐全部课程的客观测验，因此学习设计维度暂不额外加分。

## 云端回复与故障恢复

实际注入了写入前失败、写入成功但回执丢失、读取失败以及另一端更新四种情况：

1. 写入前失败保留输入，不让自动保存失败后的操作跳到下一关。
2. 服务端已保存但客户端没收到回执时，同一文字和旧版本号的重试返回成功，不重复增加版本、不报虚假冲突。
3. 不同的旧文字仍然返回冲突，保留另一端记录和当前输入；未来版本号也不能绕过版本检查。
4. 清空已有回复可保存为空，刷新后保持为空；旧文字不能借重试恢复已清空的记录。
5. “读取云端回复”实际重新请求云端，读取另一端刚保存的内容；成功后清除旧冲突，读取失败时保留输入。

这些检查使用本地正式构建、测试身份与本地 D1，没有写入用户的生产学习记录。不能据此声称已完成两台真实设备的生产登录验收。学习统计的增量响应仍保持上一轮优化：完整历史样本一次写入的 JSON 响应由 741,925 降至 308 字节；首次载入仍读取完整历史，此比例不是网页加载速度。
