# 本轮前三项质量检查

用户要求本轮集中改进使用体验、半年课程安排、翻译与点词注释。保留轻量的对话学习方式与全部关卡自由选择；语音全量人工听审及 TOPIK 测评体系不在本轮扩展范围。

## 使用体验

- 点选一个词块才显示该词注释；不出现整句展开。
- 原形读音来自结构化映射，不通过搜索中文解释猜测。
- 新课、复习课都可以直接选择；键盘可关闭词语注释和课程面板。
- 手机宽度与放大后的布局可阅读；按钮可操作，正文、提示文字和焦点可辨认。
- 云端保存失败时不前进；较早发出的读取请求不得覆盖刚完成的保存。
- 首屏不加载完整半年日程；打开安排时再加载。

## 课程安排

- 按实际收录的对话文本和原形词条计数，不把复习当新内容。
- 明确 8,154 的去重口径：韩语对话文本，含短回答及多句发言；不是 8,154 个句型。
- 两个月一组，依次安排词典初、中、高级目标词；这不是对每个完整句子的官方评级。
- 第一周新增词条最多 28 个，后续最多 60 个；学习日最多 96 条发言。
- 180 天均有课程或复习；每天安排恰好 240 分钟。
- 复习列表对应真实关卡，安排隔天、一周、一个月后再遇见；最后一个月的延后复习不假装已经在半年内完成。
- 关卡与句子 ID、句子顺序保持不变；修正一条来源中的拼写，并为新文本生成新音频，兼容原云端进度。

## 翻译与点词注释

- 句子正文仍与来源及已经记录的双语审校对应。
- 词义按整段对话从来源义项中选择，语法说明单独编写，不再拼接多个不相关词义。
- 正文、词语原形、词性、义项、注释和读音引用分别验证。
- 未匹配的义项、空注释、词形还原异常必须列出并处理，不默认选择第一个释义。
- 对已发现的真实错误保留回归用例及可追踪的编辑修正。
- 区分来源/结构检查、自动语境选择、编辑复核及教师认证。自动通过不是“全部绝对无误”的证据。

本文件是验收范围；实际完成结果与数量以对应检查报告为准，不能仅凭本文件宣称满分。
