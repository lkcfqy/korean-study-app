# 从 82 分推进至 90 分的验收范围

本轮依照内容 25、学习设计 20、体验 20、音频 15、工程 20 的相同权重改进与复评。保留轻量的逐句学习、点词查询、固定 SunHi 读音和全部关卡自由选择。

- 复核本动词/助动词义项风险及全部 어떤 用法，记录每项前后决定。已知“看电影”“给予母乳”“什么样的”和 듣다 不规则变化错误必须修正，并通过再生成回归校验。
- 听力检查在播放完成前隐藏选项，默认不显示韩文。文字提示作为可用替代路径；首次错误、未听完和回看对话应影响巩固结果。
- 登录账号保存待巩固状态和复习日程；重复或并发提交不能重复推进日程，旧客户端不能消除新产生的待巩固标记。失败重试沿用已有流程。
- 基础课 72 道题及已识别问题的 4 道扩展题使用编辑确认的对比选项。其余题目不宣称完成全量重审，答案位置保持兼容。
- 首周、第二周、第一月分别限制每日新增词条不超过 24、36、48 个；保留真实词句数量、所有课程和间隔复习。按四关分组，允许延长参考日程。
- 生产构建、类型检查、代码检查、完整内容校验、原进度兼容性及本地 D1 行为检查通过；在浏览器验证新流程与手机尺寸布局。

发布前另检查浏览器载荷：全库词句统计保留在服务端，精简目录与重复日程；验证逐日还原、完整学习历史统计以及实际构建体积。
