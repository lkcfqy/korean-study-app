## 内容修正

本轮新增编辑账本见 [editorial-corrections-20260921.json](editorial-corrections-20260921.json)，覆盖 111 关的 128 处点词修正或解释澄清，另有 1 处整句中文调整。它与之前的语境安全审查分别记录，不能把本轮工作归算为重新独立翻译了全部词典或课文。

具体包括：

- `별로였어요` 解释为“不怎么样／不太好”，负面评价与整句中文保持一致。
- 首月工资对话中的 `뭐 할 거야` 回到“打算做什么”，去掉无依据的“想买”义项；复核相同义项冲突。
- 否定疑问中的 `아냐?` 归到 `아니다`，同时保留真实 `알다` 的 `아냐고` 用法。
- 作为“东西／事情”的 `게` 与将来词尾分开，`하나` 数词与 `하다` 分开；校正 `못` 否定、体重的 `살`、刀刃的 `날`、数字整块和姓氏 `이` 等语境。
- `n26846-2-10-2` 改为“不，只是路过时见过一两次。”，补回原句具体次数与路过的语境。

来源约束、词形缓存、课程 JSON、服务端词条索引、前端目录及日程一起再生成，并通过课程验证。已确认的缺陷有回归检查，后续再生成不能静默恢复旧义项。模型提出的语义疑点另行保留接受、拒绝和待核查状态；模型标记本身不算确认错误，未覆盖部分不算审完。

## 练习与学习负荷

原来的大部分扩展题通过重复同一组选项，较容易靠排除和短期记忆答对。当前界面只在 38 关显示已有编辑对比选项；其余 3,968 关使用回忆练习：完整听完后尝试说出意思，展开韩中对照，再选择“主要意思一致”或“没想起或有遗漏”。音频不可用时可主动用韩文提示继续。使用提示、有遗漏或未完整听完都会进入短间隔巩固。

回忆结果明确写作“自评”，只用于安排复习，不声称客观测出听力水平。此改动没有逐题重写 8,012 道高质量客观题；旧选项只为兼容保留。两类练习的服务器校验、结果说明和复习行为分别验证。

登录用户可以选择 4、8 或 12 关一组，优先处理待巩固和真正到期的复习，剩余容量最多加入 4 个新关卡。复习已占满时本组不加新课。打开或读完对话不会冒充练习完成；保存完成结果后才增加本组进度。组本身是当前页面的临时安排，刷新可能重置，课程与复习进度仍由云端记录恢复。

180 天保留为可自行延长的参考路径，四小时不是对每个人适用的学习时长。当前定位仍是韩语对话精读、跟读及回忆辅助工具，未补齐完整长篇听读、受约束写作批改或经学习数据验证的零基础至 TOPIK 6 课程。

## 性能与维护

新客户端在读句、选课、完成练习和保存回复后接收当前关卡增量，并合并进已有状态。初次载入、重新聚焦与冲突恢复仍可使用完整进度。完整 4,006 关历史的测试账号中，典型写入响应由 **741,925 字节降至 308 字节，减少约 99.958%**；这是该样本未压缩 JSON 的体积差，不是网络速度或所有请求的普遍提升比例。

服务端仍读取完整历史以计算精确去重统计，首次 GET 也仍返回完整数据；本轮没有据此声称降低 D1 计算量或解决所有大账号冷启动负载。旧客户端的完整响应模式保持兼容。

新增组件和学习调度、检索、进度合并逻辑分别放置；主学习页面恢复为便于审查的多行格式。`npm run verify` 串联类型、ESLint、15 项单元/逻辑测试、课程元数据校验和生产构建。CI 工作流已经配置，版本依据官方 [checkout](https://github.com/actions/checkout)、[setup-node](https://github.com/actions/setup-node)、[setup-python](https://github.com/actions/setup-python) 用法更新；这里只确认本地流程成功，不声称远程 GitHub Actions 已运行。

## 音频审查的解释边界

转写器未获得预期韩文提示。先对所有当前文件盲转写，再将有差异的声音单独复查；识别后的数字、单位和严格语音规则对照独立记录。最新数量与证据哈希以 `audio-inventory-review.json` 为准，逐文件结果可以回查。

最终覆盖 28,778 段完整库存，并完成 12,516 段差异音频的单独转写。26,324 段在文字归一后相符，476 段仅在严格读音规则转换后相符，1,978 段仍保留转写差异。后者包括 516 段对话发言和 1,462 段词形、原形或字母声音。这些数字是筛查分类，不是语言正确率；未确证项没有被记为通过听审。

短单词和孤立词形容易出现识别歧义；转写差异仍是待核查信号，不能全部记为合成错误。反过来，文字一致或规则归一后相同也不能认证每个音素、自然重音和语调。本轮没有逐条母语听审，不把自动筛查覆盖率当作发音正确率。

## 剩余质量边界

主要剩余工作是全库独立教师审校、分层母语听审、真实设备跨端与弱网验收，以及使用者的隔天/隔周回忆和迁移效果。需要这些证据才能继续显著提高内容、音频和教学效果评分。历史的 82→90 评审另存于 [quality-result-before-20260921.md](quality-result-before-20260921.md)，不混作本次 83→91 的基准。
