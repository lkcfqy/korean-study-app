**已确认的内容问题，需要优先修正**

1. `n49297-1-7` 的 `우린 원래부터 사이가 별로였어요.` 整句中文是“我们本来关系就不怎么好啊”，但 `별로였어요.` 的点词主释义及词库释义显示“特别，格外”，解释也只是按“별로 + 이다 + 过去时”拼接，遗漏了“不怎么样”的实际语义。这会使整句翻译与点词教学互相冲突。应解释为“关系不怎么好／一般（过去）”。[课程文件](</Users/lkc/Downloads/korean learning/public/course/n49297-1-7.json:1>)。[国立国语院对 별로예요 的说明](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5742)也明确说明了这种表达的否定评价含义。

2. `n77610-1-10` 的 `지수야, 너는 첫 월급 타면 뭐 할 거야?` 整句中文正确表达“拿到第一份工资后打算做什么”，但 `할` 选用了 하다 的“想要，想买”义项，词库定义进一步写成“购买或得到某种东西”。此处是询问打算“做”什么；回答谈到买礼物，不足以把提问中的动词限定成购买。应保留做某事的动作义，并把 `할 거야` 作为将来意向结构讲解。[课程文件](</Users/lkc/Downloads/korean learning/public/course/n77610-1-10.json:1>)。

这两处问题的共同机制是：词典本身有来源，但程序选用的义项或逐词拼接并不符合句中用法。完整结构检查、义项 ID 存在和已有 AI 审校记录都未拦截这些问题。因此，内容分不能仅因库存和检查覆盖达到目标就评为接近满分。两处的完整证据另存于 `confirmed-language-findings.json`。

**扩展题能支持即时练习，但对理解程度的区分不足**

本次遍历全部 8,012 道题，其中扩展题 7,940 道：

- 7,935 道扩展题的干扰项含同段对话另一句的完整中文。
- 3,967 / 3,970 个扩展关卡，两道题使用完全相同的三个选项，只改变次序和答案。
- 逐题编写的对比选项覆盖 72 道基础题和 4 道扩展题，共 76 道，约占所有题目的 0.95%。这是特定干扰项改写的覆盖率，不能解读为其他题目没有任何既往阅读记录。

例如第一天的 `직업이 무엇입니까?`，三个选项是“我在学校当老师”“您是做什么工作的呢”“这里是图书馆吗”。另一题又沿用这组答案。学习者可能利用刚看过的对话、问句形式或已知答案排除选项，通过检查所需的理解深度有限。[示例](</Users/lkc/Downloads/korean learning/public/course/n68797-17-8.json:1>)。

这不是说这些题答案错误。问题在于将这种练习的 2/2 用作延长复习间隔的依据时，证据偏弱。比较时间、人物、否定、数量和因果的同场景干扰项，以及延迟后换句复测，能更有效地判断是否理解。当前代码保留首次错误与提示状态，这是正确方向；题目本身也需要达到相应质量。
